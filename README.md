# NexusOrch PC 后台静态改版参考

这是一个不连接真实后台的纯静态交互原型，用于给产品、设计和前端技术团队参考。

## 使用方式

直接双击 `index.html` 即可浏览。为保证浏览器剪贴板等能力正常，也可以在本目录启动任意静态 HTTP 服务。

## 已覆盖页面

- 概览面板
- 交易查询与交易详情抽屉
- 争议查询与争议详情抽屉
- 拒付预警管理与预警详情抽屉
- 预警来源配置
- 风控账户余额与资金流水
- 企业账号与子账号管理
- API 文档
- 请求日志与结构化 JSON 查看器

## 设计原则

- 保留原后台“侧栏导航 → 筛选 → 列表 → 详情”的业务逻辑。
- 统一筛选区、卡片、状态标签、表格、分页和危险操作样式。
- 长 ID 使用等宽字体；状态同时使用文字与颜色，不只依赖颜色。
- 日志默认脱敏，原始 JSON 放入独立查看器，避免直接撑开表格。
- 退款、暂停、删除、接受争议等操作仅弹出演示确认框，不会提交数据。
- 所有商户、订单、金额、邮箱、电话、密钥和日志内容均为假数据。

## 文件说明

- `index.html`：应用框架、侧栏、顶栏、抽屉和确认框。
- `styles.css`：完整 PC 后台设计规范与组件样式。
- `app.js`：假数据、页面模板和静态交互。

技术实现时可将页面模板拆成实际框架组件，并替换 `app.js` 中的演示数据为接口数据。
